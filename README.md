# DscienTia Mobile

DscienTia Mobile is an offline-first community impact reporting and analytics platform designed to support social innovation, community development, and evidence-based decision making.

## Vision

To empower communities with accessible digital tools for reporting, monitoring, and measuring social impact.

## Objectives

* Community impact reporting
* Volunteer activity tracking
* Community project monitoring
* Data-driven decision support
* Mobile-first accessibility

## Technology Roadmap

* Flutter
* Riverpod
* Supabase
* PostgreSQL
* GitHub Actions

## Academic Alignment

This repository is being developed alongside CS4405 Mobile Applications coursework at University of the People.
