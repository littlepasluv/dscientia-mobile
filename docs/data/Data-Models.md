# Data Models

## Purpose

This document defines the data structures used within the DscienTia AI Insight MVP.

The goal is to establish a clear contract between:

- Flutter Mobile Application
- Backend API
- Database Layer
- AI Intelligence Services

This document serves as the reference for:

- Database schema design
- API payloads
- Flutter models
- AI output structures

---

# MVP Data Architecture

The AI Insight MVP focuses on six primary entities:

```text
User
 │
 ├── Report
 │      │
 │      └── AI Insight
 │               │
 │               ├── Risk Assessment
 │               ├── Recommendation
 │               └── Impact Trend
 │
 └── Project
```

---

# Entity: User

Represents an authenticated platform user.

## Fields

| Field | Type | Required |
|---------|---------|---------|
| id | UUID | Yes |
| fullName | String | Yes |
| email | String | Yes |
| role | String | Yes |
| organizationId | UUID | No |
| createdAt | DateTime | Yes |

---

## Roles

```text
Volunteer
Community Leader
NGO Manager
Researcher
Admin
```

# Entity: AI Insight

Represents AI-generated analysis derived from reports.

## Fields

| Field | Type | Required |
|---------|---------|---------|
| id | UUID | Yes |
| reportId | UUID | Yes |
| summary | Text | Yes |
| confidenceScore | Decimal | Yes |
| modelSource | String | Yes |
| generatedAt | DateTime | Yes |

---

## Example

```json
{
  "summary": "Multiple reports indicate increasing water scarcity in the target community.",
  "confidenceScore": 0.84,
  "modelSource": "IBM Granite 3.3"
}
```
