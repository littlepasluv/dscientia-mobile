# DEPLOY-003 — Flutter Web Production Backend Mode

## Status

Completed.

## Purpose

This milestone redeploys the DscienTia Flutter Web app at:

    https://app.dscientia.dev

with backend mode enabled so the public Flutter MVP can communicate with the production Laravel API at:

    https://api.dscientia.dev/api

## Production Build Configuration

Flutter Web was built with:

    DSCIENTIA_USE_BACKEND_API=true
    DSCIENTIA_API_BASE_URL=https://api.dscientia.dev/api

Build command:

    flutter build web --release --base-href / \
      --dart-define=DSCIENTIA_USE_BACKEND_API=true \
      --dart-define=DSCIENTIA_API_BASE_URL=https://api.dscientia.dev/api

## Deployment Target

The Flutter Web build was uploaded to Hostinger:

    app.dscientia.dev
    /files/public_html/

## Final public_html Structure

Expected structure:

    public_html/
    ├── .htaccess
    ├── index.html
    ├── flutter_bootstrap.js

    ├── assets/

Old build folders were removed before uploading the backend-mode build.

## Verified Flow

The live Flutter app successfully performs:

    Community Risk Report form
    ↓
    POST https://api.dscientia.dev/api/reports
    ↓
    POST https://api.dscientia.dev/api/ai-insights
    ↓
    Render backend-generated AI insight result

## Verification Result

The production Flutter app displayed:

    Backend AI Insight
    Generated from the Laravel backend API using the configured AI provider contract
    High Risk
    model_provider: mock
    model_name: dscientia-local-mock-v0.1

## Current AI Provider

The production backend currently uses:

    DSCIENTIA_AI_PROVIDER=mock

This means the insight is generated by the Laravel backend mock provider, not by the previous local Flutter-only mock flow.

IBM/watsonx integration remains disabled until credentials, prompt governance, and response validation are ready.

## Production Architecture Status

    www.dscientia.dev  → public landing page
    app.dscientia.dev  → Flutter Web MVP with backend mode
    api.dscientia.dev  → Laravel API backend

## Security Notes

Do not expose or commit:

    Flutter build artifacts with secrets
    Laravel .env
    APP_KEY
    DB_PASSWORD
    WATSONX_API_KEY

The Flutter app only contains the public API base URL. All sensitive credentials remain server-side.
