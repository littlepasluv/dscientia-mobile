# Project Detail

## Purpose

The Project Detail screen serves as the operational command center for social impact initiatives managed through DscienTia.

This screen consolidates project information, activities, reports, AI-generated insights, recommendations, and measurable outcomes into a single view.

Its purpose is to help organizations understand not only what activities are being conducted, but also whether those activities are creating meaningful impact.

---

# Objectives

The Project Detail screen enables users to:

* Monitor project progress
* Review field activities
* Analyze project outcomes
* Track AI-generated recommendations
* Measure social impact
* Support evidence-based decision making

# Project Information

## Project Overview

Displays:

* Project name
* Description
* Community
* Organization
* Project status
* Start date
* End date

Purpose:

Provide essential project context.

---

## Project Status

Supported statuses:

### Planned

Project approved but not yet started.

---

### Active

Project currently running.

---

### Completed

Project objectives achieved.

---

### Archived

Project closed and retained for historical analysis.

# Progress Dashboard

## Timeline Progress

## Activity Completion
