# Recommendation Center

## Purpose

The Recommendation Center transforms AI-generated insights into actionable recommendations for organizations, community leaders, and project managers.

While the AI Insight Center explains what is happening and the Risk Assessment screen identifies why it is happening, the Recommendation Center focuses on what should be done next.

This module represents the final step of the DscienTia Intelligence Cycle:

Data → Intelligence → Risk Assessment → Recommendation → Impact

---

# Objectives

The Recommendation Center enables users to:

* Receive AI-generated action plans
* Prioritize interventions
* Allocate resources effectively
* Improve project outcomes
* Accelerate decision making

# Recommendation Components

## Issue Summary

Displays:

* Identified issue
* Related risk category
* Affected community
* AI confidence score

Example:

Issue:

Water shortages increasing across multiple communities.

Confidence:

89%

---

## Recommendation Overview

Displays:

* Recommendation title
* Priority level
* Creation timestamp
* Related project

Purpose:

Provide a quick overview before implementation.

# Priority Levels

## Low

Routine recommendation.

Implementation may be scheduled.

---

## Medium

Moderate importance.

Implementation recommended within project cycle.

---

## High

Requires prompt action.

Implementation recommended within 14 days.

---

## Critical

Immediate intervention required.

Escalation procedures activated.
