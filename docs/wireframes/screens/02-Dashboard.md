# Dashboard Screen

## Purpose

The Dashboard is the primary landing screen after authentication.

It provides users with a real-time overview of community activities, project progress, impact indicators, and AI-generated intelligence.

The dashboard serves as the operational command center of DscienTia.

---

# Dashboard Objectives

The dashboard should allow users to:

* Monitor active projects
* Review recent field reports
* Identify community risks
* Receive AI-generated recommendations
* Track impact metrics
* Access critical actions quickly

---

# Supported Roles

The dashboard adapts based on the user's role.

# Core Dashboard Widgets

## Welcome Banner

Displays:

* User name
* Organization name
* Current date

Purpose:

Provide personalization and orientation.

---

## AI Insight Summary Card

Purpose:

Provide an executive summary generated by the AI Intelligence Layer.

Inputs:

* Reports
* Activities
* Impact metrics

Displays:

* Current risk level
* Emerging trends
* Key observations
* Recommended next action

Example:

Risk Level: Medium

Trend:

Water shortage reports increased 18% during the past 30 days.

Recommendation:

Conduct community assessment in affected areas.

---

## Active Projects Widget

Purpose:

Provide visibility into ongoing initiatives.

Displays:

* Project name
* Status
* Progress percentage

Examples:

* Active
* Delayed
* Completed

---

## Recent Reports Widget

Purpose:

Display latest field activity.

Displays:

* Report title
* Submission date
* Status

Examples:

* Submitted
* Reviewed
* Approved

---

## Community Risk Alerts Widget

Purpose:

Highlight communities requiring attention.

Displays:

* Community name
* Risk level
* AI confidence score

Risk Levels:

* Low
* Medium
* High
* Critical

---

## Recommended Actions Widget

Purpose:

Convert AI insights into actionable decisions.

Displays:

* Recommended action
* Priority level

* Related project

* Low
* Medium
* High
* Critical

# Offline Considerations

When offline:

* Display cached dashboard data
* Show synchronization status
* Allow navigation to locally stored content

Synchronization occurs automatically when connectivity returns.

---

# Success Criteria

The Dashboard is successful when users can:

* Understand current community conditions in under 30 seconds
* Identify urgent risks immediately
* Access recommended actions quickly
* Monitor project performance efficiently
